使用说明

将下载的图标文件复制到你的 Capacitor 项目中：

Android 路径

  • mipmap-mdpi/ic_launcher.png → 48×48
  • mipmap-hdpi/ic_launcher.png → 72×72
  • mipmap-xhdpi/ic_launcher.png → 96×96
  • mipmap-xxhdpi/ic_launcher.png → 144×144
  • mipmap-xxxhdpi/ic_launcher.png → 192×192

iOS 路径

  • AppIcon.appiconset/Icon-App-20x20@2x.png → 40×40
  • AppIcon.appiconset/Icon-App-20x20@3x.png → 60×60
  • AppIcon.appiconset/Icon-App-29x29@2x.png → 58×58
  • AppIcon.appiconset/Icon-App-29x29@3x.png → 87×87
  • AppIcon.appiconset/Icon-App-40x40@2x.png → 80×80
  • AppIcon.appiconset/Icon-App-40x40@3x.png → 120×120
  • AppIcon.appiconset/Icon-App-60x60@2x.png → 120×120
  • AppIcon.appiconset/Icon-App-60x60@3x.png → 180×180
  • AppIcon.appiconset/Icon-App-76x76@2x.png → 152×152
  • AppIcon.appiconset/Icon-App-83.5x83.5@2x.png → 167×167
  • AppIcon.appiconset/Icon-App-1024x1024.png → 1024×1024

Capacitor 配置

在 capacitor.config.json 中确保 appId 和 appName 正确：

{
  "appId": "com.giftledger.app",
  "appName": "礼金记账",
  "webDir": "dist"
}

同步图标后运行：

npx cap sync android
